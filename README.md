## Adaptive Radial Basis Function Neural Network using Forward-Forward Algorithm in Operating Performance Assessment for Industrial Froth Flotation Process
This repository contains a **PyTorch** implementation for the paper "Adaptive Radial Basis Function Neural Network using Forward-Forward Algorithm in Operating Performance Assessment for Industrial Froth Flotation Process"

### Requirements
* numpy==2.4.1
* omegaconf==2.3.0
* pandas==2.3.3
* scikit_learn==1.8.0
* torch==2.6.0+cu124
* torchvision==0.21.0+cu124
* torchviz==0.0.3

### Preparation

```
git clone https://github.com/Galazxhy/FF-ARBFNN.git
cd FF-ARBFNN_pub
pip install -r requirements.txt
```

### Run code
```
python main.py
```

### Setting
The hyperparameters can be modified in the **config/config.py** file.
